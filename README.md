# Yuhui Qi Portfolio

## Files you normally edit

- `legacy-pages/` — website HTML pages
- `source-assets/` — the single local source for CSS, JavaScript, images, GIFs, and videos
- `config/projects.data.json` — project names and `protected: true/false`
- `lib/auth/password-page.html` — password page design

## Website system files

- `app/` — Next.js page and project-asset routes
- `lib/auth/` — password, session cookie, password page, and security rules
- `lib/legacy/` — preserves the existing HTML website inside Next.js
- `scripts/` — prepares public files and uploads project media

## Generated folders

- `public/static/` is generated from `source-assets/`. Do not edit it.
- `.next/` is generated by Next.js. Do not edit it.

## Project access

Every Case Study uses the same private media library. Change only the project configuration:

- `protected: false` — opens directly
- `protected: true` — requires the shared portfolio password

After adding or replacing Case Study media, run `pnpm assets:upload-all` to synchronize the referenced files with Vercel Private Blob.
